# push2c

Short alias for [push-to-comply](https://www.npmjs.com/package/push-to-comply),
the engine for managing a compliance program as git artifacts. Installing
this package installs `push-to-comply` and exposes its `push2c` CLI, so
either of these works:

```
npx push2c init my-compliance-program
npx push-to-comply init my-compliance-program
```

Released in lockstep with `push-to-comply` (same version numbers). All
documentation lives at
https://github.com/push-to-comply/push-to-comply.
